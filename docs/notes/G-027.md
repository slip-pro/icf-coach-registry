# G-027: Find a Coach by Name — Notes

**Status**: Achieved
**Started**: 2026-09-23
**Completed**: 2026-09-23

## Context

The filter panel narrows the catalogue by criteria but gives no way to find a particular coach.
Names in the sheet are written in Russian or English, never both, and the visitor types in
whichever script comes to hand. Plain transliteration misses (Юлия is Yulia, Julia and Iuliya),
so the design decided with the owner on 17 Sep was: reduce both sides to a rough skeleton and
compare those. Full reasoning in `BACKLOG.md`, G-027.

## What changed

- `src/js/name-search.js` (new) — `nameSkeleton()` and `matchesName()`. Lowercase, Cyrillic →
  Latin, strip accents and punctuation, then collapse spellings that vary between
  transliteration schemes. Substring match, so a surname alone works.
- `src/js/filters.js` — `name: ''` in the filter state; a search box rendered above the chips;
  the name term is ANDed with the other groups; "Clear all" resets it too. The change callback
  now also passes `{ nameQuery }`.
- `src/js/app.js` / `src/js/cards.js` — `renderCards` takes an optional `emptyKey`; the app
  shows `emptyStateName` when a name search found nobody, `emptyState` otherwise.
- `src/js/i18n.js` — `searchByName` (placeholder and aria-label), `emptyStateName`, EN/RU/EL.
- `src/styles/main.css` — `.icf-search*`, styled like the chips, full width on phones.
- `tests/name-search.test.mjs` — spelling pairs and match rules. Run: `node tests/name-search.test.mjs`.

## Decisions

- **Placement above the chips.** Finding one person is a different action from narrowing by
  criteria, and mixing it into the chip rows would read as one more filter.
- **A distinct empty message.** "No coach by that name" tells the visitor the register does not
  have the person; "no coaches match your filters" invites loosening the filters. Different next
  steps, so different sentences.
- **Word-initial Chr/Khr/Hr → Kr.** Not in the original list. The live register has three
  Christinas and a Russian speaker types Кристина; without the rule the search says she is not
  there. Cheap and covers Christos/Христос the same way.
- **No fuzzy matching, no bio search** — as scoped in the backlog card.

## Known limits

- Alexander / Aleksandr differ by a vowel, not by scheme; each is found by "Alex".
- Christina / Kristina resolve, but Michael / Михаил do not (one is a different name, not a
  spelling). Nobody in the register is affected today.
- Filter state, including the search term, resets on a language switch — the catalogue
  re-renders in full there, as it always has.
